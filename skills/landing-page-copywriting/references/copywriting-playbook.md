## Voice-of-customer mining

The highest-leverage input. Copy invented without it converts worse and reads as
AI slop. Process:

1. Gather 50-100 verbatim quotes: 3-star reviews (G2, Amazon, App Store — 3-star
   is the sweet spot: engaged but honest), support tickets, sales-call
   transcripts, win/loss notes, and community threads (Reddit, forums).
2. Bucket each quote: **pain / desire / objection / proof language / emotional
   language.**
3. Count frequency. The most-mentioned pain becomes the hero headline — in the
   customer's own phrasing, near-verbatim. Do not "improve" it into marketing
   language; the raw specificity is the asset.
4. Pull proof language and objections straight into the proof and objection
   blocks.

If the user has no research, say so and gather a lightweight sample (even 10-15
review quotes) before drafting. Never fabricate quotes, metrics, or personas.

## Copy frameworks

Frameworks are layerable (PAS hero + FAB mid-page + 4Ps close), not exclusive.

| Framework | When to use | Structure |
|---|---|---|
| **AIDA** | Cold / unaware traffic, ads, full journeys | Attention → Interest → Desire → Action |
| **PAS** | Problem-aware, retargeting, sales pages | Problem → Agitate → Solution |
| **BAB** | Audiences unaware of the gap they're in | Before → After → Bridge |
| **FAB** | Product-aware / technical, comparison shoppers | Features → Advantages → Benefits |
| **PASTOR** | Long-form, high-consideration / complex offers | Problem → Amplify → Story → Testimonials → Offer → Response |
| **4Ps** | Skeptical audiences needing trust built | Picture → Promise → Proof → Push |
| **5-part CRO arc** | Default page skeleton | Problem → Stakes → Bridge (mechanism) → Proof → CTA |
| **9-block B2B** | B2B SaaS needing early credibility | Hook → Proof → Problem → Solution → Mechanism → Results → Objection → CTA → FAQ |

The page as a whole is **one continuous argument**. Diagnostic: if you can
reorder the sections without hurting comprehension, there is no story. (Section
ordering itself is the `landing-page-structure` skill's job — this skill supplies
the words that fill the sequence.) Loss-framing ("Stop losing customers to slow
follow-up") tends to beat gain-framing.

## Awareness stages

Eugene Schwartz's five stages decide the framework and how much build-up the copy
needs:

- **Unaware** → lead with the problem/story; AIDA; long build-up.
- **Problem-aware** → PAS; agitate the known pain, present the solution.
- **Solution-aware** → differentiate your mechanism vs alternatives; FAB.
- **Product-aware** → proof, specifics, risk-reversal; 4Ps / PASTOR.
- **Most aware** → offer + CTA, minimal preamble.

Cold paid traffic skews unaware/problem-aware (fuller build-up); warm retargeting
is problem/solution-aware (compressed urgency). One page cannot serve all stages
— segment by traffic source.

## The seven objections

Answer these proactively, mid-page and near the CTA (not buried in a footer FAQ):

1. Is this real / will it actually work?
2. Does it fit *my* specific situation?
3. How does it actually work (mechanism)?
4. Are the numbers/claims real?
5. What do others like me say (proof)?
6. What's the catch / hidden cost?
7. What if I get burned (risk reversal, guarantee, easy exit)?

## Banned vocabulary & AI tells

Cut on sight — these are the recognizable "AI wrote it" signals:

- **Vocabulary:** leverage, seamless(ly), game-changer, cutting-edge, robust,
  revolutionize, unlock, elevate, supercharge, empower, "in today's fast-paced
  world", "take it to the next level", "the power of", "a myriad of".
- **Structure tells:** relentless grammatical symmetry (every sentence the same
  length), reflexive rule-of-three lists, no sentence fragments, hedge-everything
  neutrality, restating the feature name as if it were a benefit.
- **Substance tells:** claims with no number, proof with no name, urgency with no
  real deadline, "the [adjective] [category] for [audience]" headline template.

## Self-QA filter

Run every drafted line through three questions; cut what fails any:

1. Does this sound like every other page in the category?
2. Would a direct competitor put the exact same sentence on their page?
3. Does this sentence add information, or just words?

## B2B vs B2C

| | B2B | B2C |
|---|---|---|
| Reader | One person justifying to a committee | Single impulse/considered buyer |
| Tone | Direct, credentialed, ROI/risk | Conversational, aspirational, visual |
| Proof | Named case studies, security/compliance certs | Reviews, ratings, UGC |
| Length | Longer, more objection-handling | Short, scannable |
| CTA | Staged (self-serve + "talk to sales") | One decisive CTA |

Do not import B2C urgency/scarcity tactics into risk-averse B2B copy.
